KORA MUSIC COMPANION · v__COMPANION_VERSION__

Your Companion files are ready.

Kora verified and prepared the matching browser extension in extension. No separate download or extraction is needed.

  1. In Brave, paste brave://extensions into the address bar. For Chrome use chrome://extensions; for Edge use edge://extensions.
  2. Turn on Developer mode, choose Load unpacked, and select the extension folder beside this guide. It contains manifest.json.
  3. If this folder is already installed, click Reload on its extension card once, then refresh your music tabs. Older Companions need this first manual reload to gain automatic updating. If you installed a different folder, disable that copy before loading this folder.
  4. Keep Kora open and play music in your browser. It discovers supported music tabs and switches to playing music automatically.

Future updates

Update Kora, then choose Install or update Companion in dock settings. Kora updates this same folder and asks supported connected Companions to reload. It reports ready only after confirming the loaded version. A disconnected browser, an older Companion or a copy installed elsewhere may still need the manual step shown by Kora. Previous files are retained in a backup folder beside this one.

Companion is installed separately in each browser/profile. Browser permission can still require a toolbar click for live capture. The normal Beat Grid has four rows; original music playback is not delayed.

Tiện ích đã đi kèm Kora

Kora đã kiểm tra và chuẩn bị các tệp tiện ích trong thư mục extension. Lần đầu, mở trang tiện ích Brave/Chrome/Edge, bật Developer mode, chọn Load unpacked và chọn thư mục này. Nếu đã cài thư mục này, nhấn Reload một lần rồi tải lại các thẻ nhạc. Tắt bản cài ở thư mục khác để tránh trùng lặp.

Những lần sau, cập nhật Kora rồi chọn Cài đặt hoặc cập nhật Companion. Kora thay các tệp trong cùng thư mục, yêu cầu tiện ích đang kết nối tải lại và xác nhận phiên bản đã chạy. Trình duyệt chưa kết nối hoặc tiện ích quá cũ vẫn cần bước thủ công Kora hiển thị. Các tệp cũ được giữ trong thư mục sao lưu bên cạnh. Beat Grid thông thường có bốn hàng; âm nhạc gốc không bị trì hoãn.
