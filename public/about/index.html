About Kora

Kora is a task and focus workspace for personal work and shared workspaces. It brings task boards, daily planning and Pomodoro focus sessions together so you can decide what to work on next.

The public website and web app are at koraspace.online. Kora also has a Windows app with a floating Focus Dock.

Open Kora

Home is open to everyone. Sign in when you want to use tasks, music, Beat Grid or focus features. After signing in, Kora returns you to the feature you chose.

What you can use today

  • Organize tasks on boards with groups, priorities and due dates.
  • Plan today's work and pin tasks for focus sessions.
  • Run a Pomodoro timer and use the Focus Dock while working.
  • Use shared workspaces and switch between English and Vietnamese.
  • Connect supported browser music through the optional Music Companion. Playback controls and Beat Grid capabilities depend on the browser and capture support.

Project status

Kora is in Early Access and is actively being developed. Features may change, and music analysis and synchronization are still being refined. This page describes the product; it does not promise finished Beat Grid accuracy on every track.
