# Phase 3 implementation

Normal and Semantic-only now consume the existing `MusicBeatState.visualAttacks` accepted-event projection. Every identity owns a keyed instance of the existing semantic flash material, with original deadlines and row-specific duration; no counter difference manufactures additional events. Existing counter-driven geometry remains decorative when the authoritative projection exists. Untimed legacy input retains its bounded compatibility path and cannot establish normalized per-event fidelity.

`use-presentation-attacks` fences capture/source generation/epoch, admits fresh IDs on atomic owner changes, suppresses inactive/hidden/experimental-disabled input, retains independent overlapping row lifetimes and bounds its identity set. `projected-beat-flash` records commit, CSS animation start and positive-opacity RAF evidence separately through existing diagnostics. Future effects use forwards fill and remain hidden until their original deadline, including reduced mode. Event leaves are memoized; redundant legacy Bass/Lead/private-flash timers are skipped on the authoritative path. There is one nearest-expiry timer per projection consumer, with no per-frame React updates.

Existing random heart/diamond/smile shapes own `EXCLUSIVE_ACTIVE`, then a 120 ms `EXCLUSIVE_EXIT`, then `NORMAL`. Entry is resolved before semantic overlay commit. Ownership is the existing capture/epoch and moment identity; shape duration, geometry, palettes and real-onset trigger policy remain. Pattern priority suppresses ordinary visual attacks, including sustained overlays, while retaining accepted IDs in diagnostics as `pattern-exclusive`. Exit clears legacy holds; suppressed IDs are consumed and never replayed. Pause, source/capture/epoch loss, silence and inactive/hidden surfaces cancel ownership. Competing shape entry is rejected while an owner exists.

Heartbeat is a frame-level finite breath from the existing released structural tempo ticks. It never runs an independent beat timer, locks irregular music, creates a row event or increments semantic counts. A verified tempo lock and finite BPM are required. The original target ages the breath; missing pulses cannot leave an infinite oscillator. Tempo changes, pause, owner replacement, hidden surfaces and reduced motion cancel it. Semantic-only keeps decoration absent. Opal retains its selected material and renderer.

The controller change is diagnostics-only: replacing a latest-row telemetry summary no longer reports an ID as dropped when it remains in `visualAttacks`. A failing/passing regression proves the distinction. Admission, debounce, dedupe, detectors, EventTrack, Scheduler and 170 ms compensation are unchanged.

Physical limits: several accepted events inside one refresh interval can contribute to one displayed frame. Distinct DOM identities and positive software opacity do not prove separately perceived flashes, panel scanout or A/V alignment. Reduced motion exposes static local activity without geometry animation. P2 acoustic qualification remains PARTIAL.
