# Kora 0.1.33

## What's new

- **Notes.** Notes are now part of Kora for everyone:
  - Write notes, add checklists, pin notes and link them to tasks.
  - Open a note in a floating window while you work in Tasks or Focus.
  - Every edit is kept on your device first and then synced. If you go offline, restart or hit a save error, your draft is kept and Kora retries; nothing is shown as saved until the server confirms it.
- **Beat Grid.** The four-row Beat Grid now uses the Kinetic look:
  - frosted-glass idle cells and a colour for each instrument;
  - an occasional full-grid shape on the beat.

  You can choose its style and turn motion down in Floating Focus settings.

## Fixes

- **Floating Focus layout.** Toolbar icons, the music skip and volume buttons, and the timer now stay inside their buttons. They no longer overlap at any window size. The empty band above the tabs is gone.
- **Task drawer.**
  - Pressing Escape right after opening a task now closes it reliably.
  - Focus returns to the task you opened.
- **Unsaved task changes.** Leaving the page while a task change is still saving now asks you first, so a just-made move isn't lost.
- **Settings.** After closing Settings, keyboard focus returns to your profile button.

## Not in this release

- **Enhanced Beat Sync.** It stays off and is still experimental.
- **The fifth (Melody) Beat Grid row.** It stays off.
- **Music Companion.** It is unchanged at 0.3.24.
