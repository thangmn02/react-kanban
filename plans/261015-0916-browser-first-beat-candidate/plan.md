Evaluate a third detector only if trained causal weights, features and licensing can be established within the bounded search. ## Constraints and non-goals

No global delay, source timestamp rewriting, Spotify analysis workaround, invented verified EventTrack, unrelated UI redesign or deployment. Unknown media/output ownership blocks buffering. Synthetic tests are controlled timing/resolution evidence only. Natural-music completeness and physical timing require independent evidence.
