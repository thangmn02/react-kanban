# Kora Release Evaluation Report

**Status:** 🛑 STOPPED - Public publication halted due to a licensing blocker.

---

### 1. Root cause of the current user-facing failure
The previous agent implemented a `learnedPercussion` capability flag and routed audio properly, but the public distribution strictly excludes the required learned model weights due to licensing constraints. Consequently, ordinary users on Web and Desktop fall back to the heuristic detector or silence for Kick, Snare/Clap, and Hi-Hat. The application correctly prevented the native fallback from overriding the Companion, but because the Companion lacked the required public model, three of the four Beat Grid rows failed to animate for users without the private evaluation assets.

### 2. Exact licensed model and runtime selected
**None selected.** 
The existing learned percussion implementation relies on ADTOF (Automatic Drum Transcription) weights, which are licensed under CC-BY-NC-SA 4.0 (Non-Commercial, ShareAlike). This strictly prohibits commercial redistribution. The available lightweight `causal-percussion` model was trained locally as a student network using pseudo-labels generated by the ADTOF teacher model. As a derivative work of a CC-BY-NC-SA model, the student weights inherit the same distribution and commercial use restrictions. No legally distributable, rights-cleared alternative model is currently available in the project architecture.

### 3. Actual Companion packaging and installation method
*Stopped.* Public packaging was halted because a rights-cleared model could not be bundled, and shipping a heuristic fallback silently labeled as a learned detector was strictly forbidden.

### 12. Any remaining blocker
**CRITICAL LEGAL BLOCKER:** The absence of a commercially distributable, rights-cleared ML model for Kick, Snare/Clap, and Hi-Hat onset detection. The current architecture depends on CC-BY-NC-SA 4.0 ADTOF weights (or their derivative student weights), which cannot be legally packaged into a public release. Until a new model (trained on legally clear audio data without restrictive teacher pseudo-labels) is evaluated and provided, the four-row percussion feature cannot be lawfully shipped to the public.
